# Lumirins brand-site demo

A static, mobile-first brand introduction site built from the supplied product brief and image library. It has no checkout or data-collection form.

## Preview

Open `index.html` in a browser, or run a local preview from this folder:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Files

- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — product detail popups, formula switcher, and mobile navigation
- `public/images/` — selected images copied from the supplied galleries

Product benefits and ingredient descriptions are introductory copy for the visual demo. Confirm final product wording, substantiation, packaging, social URLs, and contact details before publishing.
